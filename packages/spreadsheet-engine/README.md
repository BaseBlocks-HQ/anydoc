# AnyDoc Spreadsheet Engine

A bounded, browser-compatible OOXML workbook engine for AnyDoc. It preserves
unknown package parts while exposing worksheets, styles, formulas, tables,
pivots, charts, search, range reads, selection statistics, and safe copy data.

Archive expansion, entry, part, read, search, and copy limits are enforced by
default. Consumers can lower archive limits when opening untrusted workbooks.
